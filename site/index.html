5G NR uplink research

Localizing jamming in the 5G uplink

This project uses measurements from the uplink receiver to locate interference in a slot. The resulting map lets the receiver account for interference where it occurs and gives the decoder a better estimate of which bits to trust.

Follow one slot →

From a received slot to a decoded block

After equalizing the buffered slot, the receiver measures received power (P), the pilot residual (R), and error vector magnitude (E). A U-Net uses these features to flag physical resource blocks (PRBs) by OFDM symbol. The map-aware receiver reprocesses the same slot and adjusts the bit reliabilities used for decoding.
